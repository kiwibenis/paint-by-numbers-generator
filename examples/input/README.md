# Example Input Images

The images in this directory are input for the generator. They are what the
README examples, the reference configurations and the benchmark tools in
`tools/` read.

## Origin

**These are not photographs.** Fourteen of the sixteen files were produced by
an image generation model. They are included as a test corpus, not as
photographic work, and this file exists so that a reader of the repository is
not left to guess.

Thirteen files still carry the signed C2PA manifest the generator embedded:

| Assertion | Value |
| --- | --- |
| `softwareAgent` | `gpt-image`, version `2.0` |
| `action` | `c2pa.created` |
| `digitalSourceType` | `http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia` |
| `action` | `c2pa.watermarked.unbound` |

The manifest sits in the PNG `caBX` chunk and can be read with `c2patool`:

    c2patool examples/input/portrait.png

The credentials are deliberately left intact. Stripping them would make the
files look like something they are not, and the second assertion above says
the images also carry an invisible watermark, which a stripped manifest would
not remove.
